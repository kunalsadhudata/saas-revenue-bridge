
# SaaS Revenue Bridge: MRR and ARR

## Project Overview

An end-to-end data analytics portfolio project analyzing
Monthly Recurring Revenue (MRR) movements for a fictional
subscription software company.

**Data:** Simulated subscription billing records.

## Business Problem

The CEO wants to understand:

1. Why did MRR grow by approximately 4% last month?
2. How much revenue came from new customers, expansion,
   contraction, churn, and reactivation?
3. Is the existing customer base growing or shrinking
   without new customer acquisition?

## Tools and Technologies

- SQLite — SQL revenue movement analysis
- Python — pandas validation and simulation
- Excel — MRR waterfall chart
- Power BI — Interactive three-page dashboard
- GitHub — Documentation and portfolio presentation

## Dataset

Simulated monthly subscription billing data.

Plans:
- Starter: $29/month
- Growth: $99/month
- Scale: $299/month

Period: 21 months (planned).

## Methodology

1. Generate and validate simulated billing data.
2. Classify customer revenue movements using SQLite.
3. Build and reconcile the monthly MRR bridge.
4. Independently verify calculations using pandas.
5. Calculate monthly NRR, GRR, and Quick Ratio.
6. Analyze signup cohorts and churn by plan.
7. Create Excel and Power BI visualizations.
